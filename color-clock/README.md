# Color Clock

A simple React + Vite application that displays the current time and updates the page color based on the current hour, minute, and second.

## Features

- Live updating clock display
- Color updates as time changes
- Built with React and Vite

## Prerequisites

- Node.js 18+ installed
- npm available in your terminal

## Install

From the project root:

```bash
npm install
```

## Run locally

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`).

## Build for production

Create a production build with:

```bash
npm run build
```

## Preview the production build

After building, run:

```bash
npm run preview
```

This starts a local preview server so you can verify the built app.

## How to use the app

1. Open the app in your browser.
2. The current time is shown in hours, minutes, and seconds.
3. The page color changes automatically based on the current time.
4. Refreshing the page keeps the live clock running.

## Project structure

- `src/` — application source files
- `public/` — static assets
- `index.html` — main HTML template
- `package.json` — scripts and dependencies
